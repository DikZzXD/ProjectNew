HTTP Status Codes
200
OK Request berhasil. Body JSON memakai status: true dan payload di result.
204
No Content Preflight CORS (OPTIONS). Tidak ada body.
400
Bad Request Parameter salah / kurang / format tidak valid. Baca message.
404
Not Found Path tidak ada, atau query tidak menghasilkan data.
409
Conflict State bentrok — resource sudah dipakai atau langkah belum siap.
429
Too Many Requests Limit / cooldown aktif. Tunggu sesuai pesan.
500
Internal Server Error Error di sisi Worker. Laporkan ke developer.
502
Bad Gateway Upstream gagal dihubungi atau membalas error. Coba lagi sebentar.
503
Service Unavailable Layanan sementara tidak siap (kuota / capacity). Retry nanti.
JSON status vs HTTP
HTTP

Status transport

Kode di response header: 200, 400, 502, dll. Menunjukkan hasil pengiriman request.

JSON

Status bisnis

Field body status: true|false. Sukses atau gagal di dalam envelope API.

Catatan

Keduanya bisa beda konteks

Kalau HTTP 400/502, body tetap envelope DikZzCode dengan status: false dan message yang bisa ditampilkan ke user.

Requests, bandwidth, latency, dan endpoint terpakai hanya dari 24 jam terakhir. Angka turun sendiri saat request lama kedaluwarsa — tanpa tombol reset.

Database menyimpan sesi Telegram terenkripsi AES-256-GCM. account_token digunakan untuk mengecek status dan menyinkronkan userbot.

Perintah Telegram

Fitur Lengkap Sama Seperti userbot.py

Di Telegram kamu bisa langsung memakai perintah: .help (daftar perintah), .ping (cek pong), .id (cek ID chat/user), .promosi <teks> (broadcast ke semua grup / reply pesan), .addbl, .delbl, .listbl (manajemen blacklist), .setdelay <min> <max> (jeda antar grup), dan .stop (hentikan broadcast).
